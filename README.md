# Comet-Calc-Frontend — кометы, SPA для гостя (ЛР5)

Тема: расстояние кометы от Солнца по её координатам на небесной сфере. Услуга — **комета**.

ЛР5: базовое SPA на React + TypeScript для гостя — страницы «Главная», «Лента» и «Плитка» по образцу страниц ЛР1.
Карточки берутся только из mock-коллекции (`src/modules/mock.ts`), бэкенд не нужен. Компоненты — React-Bootstrap,
маршруты — React Router. Redux и React Context не используются.

Стек: React 19, TypeScript 6, Vite 8, React Router 7, React-Bootstrap 2 (Bootstrap 5).

## Запуск

```
npm install
npm run dev      # http://localhost:3000
npm run build    # сборка в dist/
npm run lint     # oxlint
```

В `vite.config.ts` уже настроен прокси `/api` → `http://localhost:8080` (веб-сервис Comet-Calc-Backend) — понадобится в ЛР6.

## Страницы

### Меню (внизу на всех страницах)

| Пункт | Что делает |
|---|---|
| Лента | переход на `/feed` — первая опубликованная комета |
| Добавление | недоступен (серый) — откроется создателю после входа в ЛР6 |
| Плитка | переход на `/comets` |
| Вход | недоступен (серый) — страница входа появится в ЛР6 |

Активный пункт подсвечивается по текущему адресу.

### Главная — `/`

- значок и заголовок «Кометы», описание приложения;
- сводка по каталогу: число опубликованных комет, самый короткий и самый длинный период обращения;
- кнопка **Смотреть ленту** — переход на `/feed`;
- кнопка **Открыть плитку** — переход на `/comets`.

### Лента — `/feed`, `/feed/:id`, `/feed/:id?next=true`

Одна комета на весь экран, всё поверх видео:

- видео кометы на фоне (автовоспроизведение без звука, по кругу);
- снизу слева: миниатюра фото, название, краткое описание в 2 строки, кнопка **Ещё** / **Свернуть**;
- справа: период обращения (с «год/года/лет»), эксцентриситет орбиты, сердце с числом лайков;
- кнопка **↓ (следующая)** — переход на `/feed/{id}?next=true`: следующая опубликованная комета, после последней — первая.

Без id показывается первая комета, с id — комета с этим id. Адрес удалённой (46P), неопубликованной (черновик 81P),
несуществующей кометы или нечисловой id — переход на `/feed`, как в SSR-страницах бэкенда.

### Плитка — `/comets?min_orbital_period=&max_orbital_period=`

- заголовок «Кометы»;
- фильтр по периоду обращения: строка с текущим фильтром («все», «от 30», «до 80», «30 – 80»),
  слайдеры **от** и **до** (0–140 лет, шаг 1), шкала;
- кнопка **Показать** — применяет фильтр: значения попадают в адрес и сохраняются после запроса и по F5;
- кнопка **Сбросить** (видна, когда фильтр задан) — показать все кометы;
- карточки в 2 столбца: фото, название, период обращения, число лайков; клик по карточке — комета в ленте;
- если под фильтр ничего не подходит — «Нет комет с таким периодом».

Значения на краях слайдеров фильтром не считаются; если «от» больше «до», они меняются местами (как на бэкенде).

## Данные (mock)

`src/modules/mock.ts` — 10 комет из `db/seed.sql` бэкенда в формате ответа `GET /api/comets`:
8 опубликованных, черновик 81P и удалённая 46P (на страницах не показываются). Функции `getComets` и `getCometFeed`
в `src/modules/cometsApi.ts` повторяют логику методов API (фильтр по периоду, `next`) и асинхронны,
поэтому в ЛР6 их тело заменяется на запросы к веб-сервису без изменения страниц.

## Фото и видео по умолчанию

Ссылки на фото и видео в mock ведут в Minio (`http://localhost:9000/comets/…`). Хук `useMediaSrc`
(`src/modules/media.ts`) подставляет `public/DefaultComet.jpg` / `public/DefaultComet.mp4`, если поле в комете пустое
или файл по ссылке не загрузился (событие `onError` у `<img>` и `<video>`). В mock у 103P/Хартли нет ни фото,
ни видео, у 55P/Темпеля — Туттля нет видео. Если Minio не запущен, файлы по умолчанию показываются у всех комет.

## Хуки

| Хук | Где | Зачем |
|---|---|---|
| `useState` | CometsPage, FeedPage, HomePage, `useMediaSrc` | значения слайдеров, загруженные кометы, раскрытие описания, сбойный адрес файла |
| `useEffect` | CometsPage, FeedPage, HomePage | загрузка данных при открытии страницы и смене фильтра или id; отмена устаревшего ответа при размонтировании |
| `useParams` | FeedPage | id кометы из адреса |
| `useSearchParams` | CometsPage, FeedPage | фильтр `min/max_orbital_period` и признак `next` из адреса |
| `useNavigate` | CometsPage, FeedPage, HomePage | переходы по кнопкам и карточкам, редирект с удалённой кометы |
| `useLocation` | TabBar | подсветка активного пункта меню |
| `useMediaSrc` (свой) | CometPhoto, CometVideo | адрес файла или файла по умолчанию |
